# Tropical raft course: environment README

An original stylized tropical canyon river course for a shared-raft obstacle game. All geometry, shaders and props are generated by editor code with a fixed seed; there are no imported art packs or textures, apart from one generated soft-dot texture.

Scene: **`Assets/Scenes/TropicalRaftCourse.unity`** (environment only, with a paddle test raft). The playable game scene `Assets/Game/Scenes/RaftCourse_Game.unity` is a copy of it plus the game systems.

## Course (475 m)

| Section | Content |
|---|---|
| A: jungle lagoon start | wide calm lagoon, start dock, striped start gate, checkpoint 0 |
| B: narrow canyon | 9.5–10 m channel between tall red/orange walls, canyon gate, overhead beam, slalom low beam, checkpoint 1 |
| C: waterfall basin | wide basin with three waterfalls, a central boulder (clear passage on both sides), checkpoint 2 |
| D: rapids S-curve | winding fast channel with turbulence foam, rotating sweeper, checkpoint 3 |
| E: water ramp and jump | chute dropping 4 m (flow up to 8.5 m/s), striped warning posts, rock kicker at the lip, about 7 m dry gap over the falls, landing basin, checkpoint 4 |
| F: final arena | big chamber, two pendulum logs, a moving barrier, finish gate with chequered banner and confetti, finish dock, 47 m landmark waterfall |

A `HazardZone` sits below the whole course (it triggers a wipeout).

## How it is built

**Menus** (Tools > Tropical Course): *Build Graybox Scene*, *Reset Layout To Default*, *Rebuild Materials*, *Rebuild Prop Library*, *Rebuild Dressing and Background*, *Rebuild Obstacles*, *Capture Previews*.

**Geometry**
- `RiverPath`: a centripetal Catmull-Rom spline of `RiverPoint`s (water height, width, bank flat, wall height and overhang, flow speed, section, `hasWater`).
  - Arc-length samples drive everything else.
  - A segment is wet only if **both** of its end points are wet.
- `RiverTerrainBuilder` sweeps one continuous cross-section (bed, banks, 12 wall rows with ledges and cracks, plateau) into 10 chunks. It also builds separate collision meshes and the water ribbons.
- `WaterfallBuilder`: 9 falls (ballistic sheet, mist and splash particles, wet zones on the rock), plus impact foam drawn by the water shader through a global `_FoamSpots` array.
- `PropFactory` / `DressingPlacer`: 6 rock and 16 vegetation prefabs (palms, broad-leaf plants, ferns, grass, shrubs, jungle trees, vines) with LOD culling.
  - About 560 placed props, a background ground grid with 260 trees, and in-water rocks only where the raft still has room.
- `ObstacleBuilder`: rounded wooden beams with red/white hazard paint (vertex colours) and kinematic time-driven movers (`Pendulum`, `RotatingSweeper`, `MovingBarrier`), plus `Checkpoint`, `FinishGate` and `HazardZone` triggers.

**Shaders** (texture-free URP)
- `Env/StylizedSurface`: Rock / Foliage / Wood modes, strata, crevices, wet darkening, wind.
- `Env/StylizedWater`: depth colour, refraction, flow-map waves and foam (time-only flow phase), edge foam, foam spots.
- `Env/Waterfall`.

**Tuning** lives in `Assets/Environment/Settings/TropicalCourseSettings.asset` (seed, scales, densities, palette).

## Runtime scripts (`Assets/Environment/Scripts`)

| Script | Role |
|---|---|
| `RiverPath` | Spline; queries (`Closest`, `TryGetWater`, `SampleAtDistance`); gizmos |
| `RaftBuoyancy` | Point buoyancy plus current drag (stronger grip in fast water) |
| `WaterCurrentController` | Global current strength |
| `RaftChaseCamera` | Damped chase with river look-ahead and wall avoidance |
| `KinematicObstacle` and subclasses | Deterministic movers |
| `Checkpoint` / `FinishGate` / `HazardZone` | Triggers; they talk to any raft implementing `ICourseRaft` |
| `TestRaft` | Paddle test raft |
| `EnvironmentAudioHooks` | Optional audio sources and splash detection |

## Editing the course

1. Edit `Editor/CourseLayout.cs` (route points).
2. Run *Reset Layout To Default*, then *Rebuild Dressing and Background*, then *Rebuild Obstacles*.
3. Run *Tools > Fart Online > Build Game Scene* to refresh the playable scene.

When adding a dry span, put wet points close on both sides.
